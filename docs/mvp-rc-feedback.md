# Local Control Panel feedback

Use the build identifier in the window title or the `?` build details. From a
terminal, `control --version` also reports the source identity without starting
settings providers. Include that identity with each report.

The five-working-day trial starts after the candidate's qualification gates pass.
Until then, scenario checks and blockers belong in the qualification record.
Keep the existing KDE tools available for functions outside the qualified scope.
Application-file rollback restores application files only; it does not undo
preferences changed while using the candidate.

```text
Date / build:
What I was trying to do:
Page and steps:
Expected / actual result:
Error text or screenshot, if useful:
Workaround or tool I fell back to:
How much it interrupted the task:
```

Prioritize configuration loss, incorrect writes and recovery failures, then
blocked tasks, confusing interactions and visual polish. For a failed mutation,
retain its error and background-job details; stop retrying if the result is
uncertain and record the current state before making another change.

Record every occasion that requires another settings tool. A daily log can
contain several records; there is no telemetry service or automatic upload.
Do not include passwords, wireless secrets or private file contents in feedback.
